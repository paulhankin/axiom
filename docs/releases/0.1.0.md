# Axiom 0.1.0

The first release: the language as specified by `docs/spec.md` (v0.1), the compiler,
and the standard library.

## The compiler

- `axiom build`, `check`, `test`, `profile`, `fmt`, `new`, `lsp`, `cache` and
  `version`, for WebAssembly (`wasm32`, `wasm64`) and native code on Linux (x86-64,
  AArch64), macOS (Apple silicon) and Windows (x86-64).
- Its own backends and linkers: it needs no LLVM, C compiler or linker, and native
  programs need nothing but the system's own libraries (none on Linux).
- Packages (`axiom.toml`, path and git dependencies), separate compilation with a
  module cache, stack traces, error return traces, a sampling profiler, an address
  sanitizer, and diagnostics for agents (`--format=agent-json`).

## The standard library

Containers, strings and Unicode, files and processes, threads, networking (TCP, UDP,
DNS, HTTP/1.1 and HTTP/2, WebSocket, TLS 1.3), cryptography, time zones, compression and
archives, data formats (JSON, TOML, YAML, XML, CBOR, MessagePack, protobuf), text
(regular expressions, HTML, Markdown, TeX math), images, fonts and text shaping, 2D
drawing, PDF and SVG, audio, and windows and GPU graphics on macOS and Windows. See
`std/README.md`.
