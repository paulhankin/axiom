## C

- The GNU dialects have the integer complex types: `_Complex int`, `_Complex unsigned
  char`, `__complex__ long long` and the others of an integer type (not `_Bool`,
  `_BitInt` or `__int128`), with integer imaginary constants (`2i`, `3ui`), their
  arithmetic, comparisons, conversions and constant folding, passed and returned as the
  platforms' C compilers pass them.
