# 0042: No 128-bit integers

- Type: feature
- Status: open
- Area: language, compiler (C and selfhost)

the benchmark's position cache keys are 128 bits (`u128` in Rust: hashed, compared and stored as
one value). The Axiom port keeps them as a struct of two `u64` (`Key128`), with hand-written
equality and hashing, and every key copy is an aggregate (see issue 0040).

Proposal: `u128` and `i128` with the usual operators and checked/wrapping/saturating forms,
lowered to LLVM's `i128` (two registers natively, two `i64` on wasm32), `@clz`/`@ctz`/
`@popcount`, conversions with `@as`/`@truncate`/`@int_cast`. (The self-hosted compiler
already has `i128` in its formatter test, so some support exists.)
