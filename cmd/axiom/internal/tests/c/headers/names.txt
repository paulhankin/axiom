# names.txt - the identifiers each standard header may introduce, by
# standard, written from the synopses of C89 (with Amendment 1: c95), C99,
# C11, C17 and C23 and their clauses on reserved identifiers (7.1.3) and
# future library directions (C89 4.13, C99 7.26, C11 and C17 7.31, C23
# 7.33). cmd/axiom/internal/tests/tools/c_header_names.mjs preprocesses each
# header alone in each --c-std and checks that every identifier it declares
# or defines as a macro is one of its standard's, reserved, or a keyword;
# and that each name listed (without ?) is there.
#
#   [name.h] std        a header, from the standard std on (before it, an error)
#   std name ...        names of the header from std on (std-std2: through std2)
#   ?name               a name the standard permits but does not require here
#                       (an optional feature, or another part's function not
#                       provided): allowed, not checked for
#   reserve std /re/    names the standard reserves to the header (a regex)
#   include name.h      the names of that header too (the standard says it
#                       includes it)
#   ext1 name ...       Annex K's names, with __STDC_WANT_LIB_EXT1__ 1 (K.3)
#
# Standards: c89 c95 c99 c11 c17 c23. Member names are listed where the
# standard names them (they are the header's, and a program's macro of that
# name would break it); parameter names must not appear at all.
