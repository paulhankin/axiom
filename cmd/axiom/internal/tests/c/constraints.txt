# constraints.txt - one program or more for every Constraints paragraph of
# clause 6 of the C standards (C17's numbering; C23's where it added one),
# and the constraints of 5.1.2.2.1 and 6.10.8: tools/c_constraints.mjs
# checks that each "!" program is rejected with its code and each "+" one
# accepted. docs/c-conformance.md indexes them. The default standard is c17.
